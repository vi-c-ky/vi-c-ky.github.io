Multi-Omics Factor Analysis Identifies a Pan-Cancer Immune Exclusion Programme with Tissue-Specific Mechanistic Drivers

Unsupervised MOFA2 analysis across 11,060 TCGA samples spanning 31 cancer types identifies a conserved CEACAM5/B-cell exclusion programme, independently prognostic in the discovery cohort. Dissociated Cox modelling separates tissue-specific mechanistic drivers; external validation in an independent cohort (METABRIC) reported honestly, including a negative prognostic replication result.

Projects

Drug discovery · AI for health
01 — Featured

QSAR Drug
Side Effect Predictor

End-to-end drug adverse effect prediction system for early-stage drug safety screening. Multi-label classifier trained on ChEMBL + SIDER across 15 adverse effect labels. Molecular featurisation using Morgan fingerprints (r2-r5) and 14 RDKit physicochemical descriptors. Weighted loss for class imbalance; atom-level SHAP interpretability for clinical explainability. Full-stack deployment with Flask REST API and JavaScript frontend.

15 AE labels · SHAP interpretability · Flask + JS

PyTorch RDKit scikit-learn SHAP Flask

02

TumorEvo: Resistance Dynamics

Four-compartment ODE model (sensitive, resistance A, resistance B, dual-resistant) modelling acquired resistance dynamics relevant to clinical treatment planning. RK4 numerical integration; four clinical dosing schedules (continuous, pulsed, metronomic, escalating); real-time growth/death flux analysis and resistance dynamics visualisation. Full-stack web application with interactive parameter controls.

NumPy SciPy Flask Chart.js ODE
GitHub ↗
03

SideGen: Conditional Molecular Generation

Conditional GNN-VAE for inverse molecular design: generates candidate molecules conditioned on a target side-effect profile, closing the loop with the QSAR predictor (structure→effect and effect→structure). Systematic conditioning validation across 8 side-effect classes. Dataset expansion via DrugCentral in progress to improve generation quality.

PyTorch GNN VAE RDKit
GitHub ↗

TrialSight

Clinical trial recruitment risk predictor trained on 80,000+ ClinicalTrials.gov records. XGBoost classifier with SHAP interpretability surfaces which trial design factors (eligibility complexity, site count, condition rarity, sponsor type) most increase recruitment risk. Deployed as an interactive dashboard for pre-launch risk assessment.
